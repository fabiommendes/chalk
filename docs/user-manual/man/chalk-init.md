# chalk-init(1)

## NAME

chalk-init - initialize a Chalk project

## SYNOPSIS

chalk init <options>

## DESCRIPTION

Creates a new Chalk project in the current directory.

## OPTIONS

`-c, --classroom TEXT`
:   Specify the classroom name for the project. Interactive if not provided.

`-t, --teacher TEXT`
:   Specify the teacher name for the project. Interactive if not provided.

## EXAMPLES

```bash
chalk init --classroom programming-101 --teacher "Grace Hopper"
```
