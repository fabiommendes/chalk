# chalk-info(1)

## NAME

chalk-info - display information about a Chalk project

## SYNOPSIS

chalk info <options>

## DESCRIPTION

Displays detailed information about a Chalk project.

## OPTIONS

`-c, --classroom`
:   Show basic classroom/project information and statistics.

`-d, --debug`
:   Show debug information about the Chalk project and environment.

`-v, --version`
:   Display the version of Chalk and key dependencies.

## EXAMPLES

```bash
chalk info
```
