# Chalk Documentation

Chalk is a classroom management CLI focused on local, text-based workflows.

This site is split into two documentation tracks:

- User Manual: command-oriented docs written in a man page style.
- Developer Docs: architecture and API reference generated automatically from source code.

## Quick start

1. Install dev dependencies.
2. Run the docs server.

```bash
uv sync --group dev
uv run mkdocs serve
```

The local site will be available at http://127.0.0.1:8000.
